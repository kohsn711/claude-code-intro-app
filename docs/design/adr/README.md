# Architecture Decision Records

重要な技術、セキュリティ、データ設計の決定だけを記録する。小さな実装判断は各チケットへ記録する。

## 状態

- `proposed`: 提案中
- `accepted`: 採用中
- `superseded`: 後続ADRに置換済み
- `deprecated`: 非推奨
