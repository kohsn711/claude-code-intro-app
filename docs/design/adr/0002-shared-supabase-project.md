# 0002 Supabaseプロジェクトの当面の共有

- Status: accepted
- Date: 2026-08-12

## 背景

現在はテストアカウントだけで、Supabase Freeプランの単一プロジェクトを本番、Preview、ローカルから利用している。環境分離には安全面の利点があるが、現段階では追加の管理負荷が大きい。

## 決定

- 当面は本番、Preview、ローカルで同じSupabaseプロジェクトを使用する。
- Previewとローカルではテスト専用アカウントとテストデータだけを使用する。
- Previewには公開可能なURLとpublishable keyだけを設定し、service role keyは設定しない。
- DBマイグレーション前と本番リリース前にDBとStorageをバックアップする。

## 影響

環境構成は簡潔になるが、Previewやローカルの操作が本番DBへ直接影響する。実利用者の登録前、または誤操作リスクが許容できなくなった時点で、Supabaseプロジェクトの分離を再検討する。
