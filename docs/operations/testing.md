# テスト運用

## 方針

MVP期間中は自動テストを導入せず、変更機能と主要な認証・権限項目を手動確認する。将来、実機確認の負担や回帰が問題になった時点でPlaywrightや単体テストを検討する。

PRごとにCIで次を自動確認する。

```bash
npm ci
npm run lint
npm run typecheck
npm run build
```

## 本番で確認済みの範囲

2026-08-12時点で、テスト専用アカウントを用いて次を確認済み。

- 学生・監督・保護者・管理者のログイン
- 未認証ユーザーの`/login`リダイレクト
- 日次記録6カテゴリの作成、保存、詳細表示、再編集
- 目標の作成、編集、達成、断念、再開
- 監督のチーム作成と学生のチームコード参加
- 保護者招待、OTP初回設定、親子リンク承認
- 監督・保護者による記録閲覧、リアクション、コメント
- 学生へのアプリ内通知と既読化
- 監督・保護者・学生のコメント／リアクション可視性
- 管理コンテンツの作成、編集、公開、非公開、アーカイブ、対象ロール閲覧
- サムネイルアップロードと外部動画表示
- 学生が他学生の記録を閲覧できないこと
- 監督が他チーム学生の記録を閲覧できないこと
- 保護者が未連携学生の記録を閲覧できないこと
- 非管理者が`/admin`を閲覧できないこと
- iPhone ChromeでPWAのホーム画面追加とstandalone起動

未確認:

- iPhone SafariでのPWA確認
- Android ChromeでのPWA確認
- DB APIを直接呼ぶ不正操作の網羅試験
- 復元リハーサル

## PR前の手動確認

- 変更した機能の正常系と主要な異常系
- 未認証アクセス
- 変更に関係するロール境界
- 長い入力や不正なURLなど変更箇所の入力境界
- スマートフォン幅での表示

## 本番反映後

- Vercel Productionが`Ready`であること
- ログインできること
- 変更した主要操作が完了すること
- Vercel Logsに新しい例外が出ていないこと
- 結果を対象チケットの進捗ログへ残すこと
