# 28 本番認証メール

> ステータス: 未着手

## 目的

Supabase標準メールの送信制限に依存せず、招待・OTP・パスワード再設定メールを実利用者へ安定して届ける。

## 対象

- Resendを含むSMTPサービスの再比較と選定
- 送信ドメインの取得または既存ドメイン利用
- SPF、DKIM、DMARCとSupabase custom SMTPの設定
- 招待、OTP、パスワード再設定のテンプレートと到達確認
- bounce、苦情、送信障害の確認方法
