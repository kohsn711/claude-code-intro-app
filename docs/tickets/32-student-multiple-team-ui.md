# 32 学生の複数チーム所属UI

> ステータス: 未着手

## 目的

DBと要件が許可している複数チーム所属を、学生マイページでも正しく取得・表示し、所属後も追加のチームへ参加できるようにする。

## 現状

- `team_members`とチーム参加RPCは複数所属を許可している。
- 学生ホームは所属チームを複数取得できる。
- 学生マイページは`.maybeSingle()`で単一所属を仮定し、1チーム所属後は参加リンクを隠す。

## 完了条件

- [ ] 学生マイページで所属チームを配列として取得する
- [ ] 複数の所属チーム名を表示する
- [ ] 所属済みでも追加のチーム参加導線を表示する
- [ ] 未所属、1チーム、複数チームで表示を確認する
- [ ] 重複参加や不正なチームコードの既存制御を維持する
