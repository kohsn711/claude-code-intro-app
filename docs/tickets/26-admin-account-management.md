# 26 管理者向けアカウント管理

> ステータス: 未着手

## 目的

実利用開始後にSupabase Dashboardへ依存せず、管理者が学生・監督アカウントを安全に運用できるようにする。

## 要件

- 学生・監督を招待メールで登録する
- 学生、監督、保護者、管理者を一覧・検索する
- アカウントは削除ではなく無効化する
- 招待、無効化、再有効化などの管理操作を監査ログへ残す
- 保護者の新規登録は既存の学生起点の招待フローを維持する

## 完了条件

- [ ] service role keyをクライアントへ露出せず、管理者だけが操作できる
- [ ] Auth Admin APIとDBプロフィール更新の失敗時挙動を設計している
- [ ] 招待・一覧・検索・停止・再有効化が動作する
- [ ] 管理操作ログを改ざん困難な形で確認できる
- [ ] 全ロールの権限境界を手動確認する
