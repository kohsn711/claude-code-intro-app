# 27 パスワード再設定

> ステータス: 未着手

## 目的

学生、監督、保護者、管理者が管理者対応なしでパスワードを再設定できるようにする。

## 要件

- ログイン画面から再設定メールを要求できる
- メール内リンクから新しいパスワードを設定できる
- Redirect URLと期限切れ・無効リンクを適切に扱う
- アカウントの存在を第三者へ推測させない表示にする
- 管理画面からの再送機能は初回対象外とする

## 完了条件

- [ ] 全ロールで再設定が成功する
- [ ] 未登録メール、期限切れ、使用済みリンクを確認する
- [ ] open redirectやセッション取り違えがない
- [ ] 本番SMTPで到達を確認する
