# びーびー日記 開発ロードマップ

## 役割

この文書はフェーズ構成と役割分担の索引。優先順位と実行状態は[実行計画](plan.md)、個別作業は[tickets](tickets/README.md)を参照する。

## 役割分担

| 担当 | 範囲 |
| --- | --- |
| Codex | 調査、詳細設計、実装、検証、レビュー、関連文書更新 |
| ユーザー | 要件決定、実機確認、外部サービス設定、PR確認・マージ |

## フェーズ

| フェーズ | 内容 | 状態 |
| --- | --- | --- |
| MVP実装 | 4ロール、日次記録、チーム、親子連携、反応、通知、コンテンツ、PWA Phase 1 | 主要機能は本番確認済み。PWAはiPhone Chrome確認済み、他端末未確認 |
| 開発基盤再整備 | 文書正本、CI、秘密情報スキャン、Dependabot、AI引き継ぎ | 進行中 |
| セキュリティ更新 | Node.js 24統一、Next.jsと依存関係の脆弱性対応 | 最優先 |
| 実利用準備 | アカウント管理、認証メール、パスワード再設定、法務、バックアップ、2FA | 未着手 |
| 改善 | 既知不具合と利用体験の改善、必要に応じた自動化・監視 | 後続 |
| PWA拡張 | オフライン対応、Web Push | 将来対応 |

## 進め方

1. 大きな作業は着手時に`docs/tickets/`へ起票する。
2. `develop`で実装し、ローカル検証とAIレビューを行う。
3. PRのCIとVercel Previewを確認する。
4. ユーザーが`main`へマージし、本番をスモーク確認する。
5. 実機確認や本番結果などGitから分からない情報を文書へ残す。
