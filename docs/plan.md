# 実行計画

全体の優先順位とマイルストーンの一次ソース。個別状態は各チケット内のステータスと進捗ログを正とする。

## 現在地

主要MVPは本番稼働済みで、テストアカウントによる4ロールの動作確認まで完了している。開発基盤再整備を完了し、現在は依存関係と実行環境を更新してから実利用開始前の必須課題へ進む段階。

## 優先順位

### M1: 開発基盤再整備（完了）

- 文書をrequirements / design / operations / tickets / meetingsへ再編する。
- Codex向け`AGENTS.md`と`wrap-up` Skillを整える。
- GitHub Actions CI、gitleaks、Dependabotを導入する。
- サービス表示名を「びーびー日記」へ統一する。
- 新規セッションでコールドスタート試験を1回行う。

### M2: 依存関係と実行環境の更新

- Node.jsをローカル・CI・Vercelで24へ統一する。
- Next.jsを含むhigh判定の依存脆弱性を解消する。
- 4ロールのログインと主要権限境界を再確認する。

### M3: 実利用開始前の必須機能

- 管理画面から学生・監督を招待し、ユーザー一覧・検索・停止・管理操作ログを提供する。
- 本人向けパスワード再設定を提供する。
- 独自SMTPと送信ドメインを選定し、認証メールの到達を確認する。
- 利用規約、プライバシーポリシー、保護者同意、データ保持方針を専門家確認のうえ実装する。
- 問い合わせ窓口を用意する。

### M4: 本番運用準備

- DBとStorageの手動バックアップ・復元をリハーサルする。
- GitHub、Vercel、Supabaseの2FA/MFAを有効化する。
- GitHubリポジトリをPrivate化し、Vercel自動デプロイを再確認する。
- PreviewへSupabase公開環境変数を設定し、テスト専用アカウントだけで確認する。
- 認証情報をBitwardenへ移し、Notionから削除する。

### M5: 改善

- 学生マイページを複数チーム所属に対応させる。
- 既知の不具合・改善要望を別途整理して優先順位を決める。
- MVP中は手動テストとVercel Logsを使う。
- 実利用開始後、バックアップ自動化、自動テスト、外部監視、Analytics、Speed Insightsを再評価する。
